Som de finalização
===================

O arquivo usado pela urna é: final.mp3

Você pode substituí-lo por outro MP3 curto mantendo exatamente o nome final.mp3.
Também é possível enviar outro MP3 pela Administração > Configuração da eleição.
Recomendação operacional: use um som curto; o sistema não espera o áudio terminar para imprimir ou finalizar o voto.
