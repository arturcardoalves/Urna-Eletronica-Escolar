# Imagens da documentação

As imagens desta pasta são públicas e não contêm dados reais de alunos.

| Arquivo | Origem |
|---|---|
| `capa.svg` | Arte vetorial de apresentação; não é uma tela do sistema. |
| `visao-geral.svg` | Diagrama explicativo de Central, rede local e Urna. |
| `urna-aguardando.jpg` | Captura da interface oficial na espera de liberação. |
| `urna-escolha.jpg` | Captura da seleção por mouse, com chapas e nomes fictícios. |
| `urna-confirmacao.jpg` | Captura atualizada em 12/10/2026: cartão compacto e CORRIGIR vermelho. |
| `urna-impressao.jpg` | Captura de FIM/VOTOU; estado da impressora simulado. |
| `painel-central.svg`, `painel-urna.svg` | Ilustrações antigas dos aplicativos de apoio; não são screenshots. |

As quatro capturas usam os templates, estilos e scripts oficiais em uma prévia isolada. As respostas do servidor e da impressora foram simuladas, sem banco eleitoral real. As resoluções variam conforme o tamanho da janela usada. Não foram usadas as telas do mini executável de teste.

O empacotador inclui explicitamente as quatro capturas JPEG revisadas. Antes de incluir outras imagens, confira se não há nomes reais, senhas, tokens, endereços privados ou dados eleitorais. Nunca copie fotos de eleições ou uploads do sistema para esta pasta automaticamente.
